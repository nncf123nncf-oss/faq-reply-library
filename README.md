# FAQ返信集

店舗やサロンを運営する個人事業主向けの、よくある質問への返信をためておく道具。

## 解決する困りごと

営業時間・料金・予約方法など、**同じ質問への返信を毎回探している。**

スマートフォンのメモや過去のDMをさかのぼると、返信に時間がかかり、
そのたびに言い回しが変わり、忙しい時間帯には返しきれなくなる。

登録しておいた返信文をキーワードで探して、ボタン1つでコピーする。

## 使い方

1. 「よく聞かれること」と「返す文章」を書いて登録する（種類も選べる）
2. 問い合わせが来たら、検索欄にキーワードを入れる
3. 出てきた返信文の「この返信をコピー」を押す
4. InstagramのDM・LINE・メールに貼り付ける

初回はサンプルが3件（営業時間・予約方法・キャンセル）入っている。不要なら削除できる。

## 主な機能

- 質問・返信文・種類を登録する
- **質問文だけでなく返信文の中身も検索する**（「キャンセル」のように、質問文には出てこないが返信文には書いてある語で引ける）
- 種類（営業時間 / 料金 / 予約 / 場所 / その他）で絞り込む
- 返信文をコピーする（コピーした旨を表示）
- よく使う返信に★を付けて上に固定する
- 削除する（確認を挟む）

## 設計上の決めごと

- **AIや外部APIは使わない。** 通信は一切発生しない
- **入力は外に出さない。** 保存先はブラウザの `localStorage`（キー: `faq-reply-library:v1`）だけ
- **表示は安全に。** 返信文はReactのテキストノードとしてのみ描画し、HTMLとして解釈しない（`dangerouslySetInnerHTML` は不使用）
- **保存の失敗を隠さない。** 容量超過やプライベートモードで保存できなかったときは画面に出す。黙って失敗すると、書き溜めた内容が再読み込みで消える
- **検索は全角・半角を揃えてから比べる**（`NFKC`）。日本語入力では「１０:００」「ｷｬﾝｾﾙ」が普通に混ざるため
- **0件は4つに分ける。** 「1件もない」「検索で見つからない」「この種類に無い」「絞り込み中の検索で見つからない」。最後の1つを「無い」と伝えると、登録済みの返信文をもう一度作らせてしまう
- **idは `crypto.randomUUID()`。** 読み込み時に重複idも落とす（削除やコピーが別の項目に当たるのを防ぐ）

## ファイル構成

```
src/
├── types/faq.ts                型・カテゴリー定義・サンプルデータ・入力上限
├── utils/storage.ts            localStorage の読み書き（壊れた値の除去を含む）
├── utils/search.ts             検索・絞り込み・0件判定
├── components/FAQForm.tsx      登録フォーム
├── components/FAQList.tsx      一覧と0件表示の出し分け
├── components/FAQCard.tsx      FAQ1件（コピー・削除・★）
├── App.tsx                     状態の保持と保存
├── App.css                     画面のスタイル
└── index.css                   配色・書体の定義（ダークモード対応）
```

見出しは明朝、本文はゴシックで組んでいる。日本語の明朝を持たない端末では
ゴシックにフォールバックする（Webフォントは読み込まない。通信を発生させないため）。

## 使用技術

React / TypeScript / CSS / Vite / localStorage / Clipboard API

## 起動方法

```bash
npm install
npm run dev
```

ビルドは `npm run build`（出力先は `docs/`）。

## 既知の問題・未完成部分

- **登録した返信文を編集できない。** 直すには削除して登録し直す
- **バックアップ・書き出しができない。** ブラウザのデータを消すと失われる
- 検索が返信文の中身にヒットしたとき、**どこがヒットしたのか画面から分からない**（質問文に語が出てこないため、件数が増えると理由が読み取れない）
- 読み込み時に重複idを落とすが、そのことを利用者に知らせていない
- **自動テストは書いていない。** 確認はビルド（型チェック込み）と、ブラウザでの手動操作・DOM実測のみ
- スタッフ間の共有、FAQの編集履歴には対応していない（データベースの導入が必要）
